## Rules the generator applies

- **Aliases** use the v5.3 rules: `__dev — row` → `row`, `sml__footer` stays, helpers (`🚫 …`) get none.
- **Option owners** come from definition-tree bindings, not from naming. A prop whose value is bound
  to a helper component's variant takes that helper's options (`col.Align` → `🚫 __dev — flex align`).
- **Defaults** are the real values on a fresh instance. `col.Align` defaults to `stretch`, not `base`;
  `equals_default` compares against this, so `Align=start` is written as `base`.
- **Grouped props** keep their group: `Top.Padding`, `Tab 1.Visibility`. The DSL also accepts
  `"Top :: Padding"`, and a bare label when only one group has it (`Autoplay`); a bare `Padding`
  matches two groups and is rejected as ambiguous.
- **Slots** list runtime names in definition order. A duplicate name marks later slots `unreachable`.
  A slot whose name cannot be resolved blocks the component until probed.
- **Digest** changes only when aliases or components change; the timestamp does not affect it.
